# Accurx/.github

Default community health files for the Accurx GitHub organisation.

## Default pull request template

[`PULL_REQUEST_TEMPLATE.md`](PULL_REQUEST_TEMPLATE.md) is the PR template for every Accurx repo that doesn't have its
own. A repo with its own template (in its root, `docs/` or `.github/`) keeps using that one instead.

It started as a copy of rosemary's template.

## This repo is public

GitHub only picks up these defaults from a public `.github` repo, so anything committed here is visible to anyone. Keep
internal links, names and anything confidential out of it.

Don't add `profile/README.md` unless you mean to: GitHub shows it on the organisation's public profile page.
